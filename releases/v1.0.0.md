# DesktopDDL v1.0.0

首个公开版本：Windows 原生桌面 DDL 提醒栏。

## 下载与安装

下载下方附件 **`DesktopDDL-Setup.exe`**，双击按中文向导安装。仅为当前用户安装，无需管理员权限，支持 Windows 10/11。

- `DesktopDDL-Setup.exe`：完整安装包，安装过程中无需联网。
- `DesktopDDL-Setup.exe.sha256`：SHA-256 校验文件。
- GitHub 自动提供的 Source code 是源码，不是安装包。

安装包未做代码签名，可能显示未知发布者提示，请确认文件来源。需要系统 .NET Framework 4.x。

## 功能

- 右上角白色箭头，两级悬停展开待办，按 DDL 排序、逾期标红。
- 新建、编辑、完成、恢复和删除事项；自定义悬停展开数量。
- 图文说明支持粘贴截图及本地文件链接。
- 原生 WinForms 管理窗口、托盘入口、可选登录启动。
- 配套「切角档案 + 时钟」应用图标与简化托盘图标。
- 安装、覆盖升级和卸载，卸载保留事项数据。

## 已有用户

事项保存在 `%LOCALAPPDATA%\DesktopDDL`。安装版会自动读取便携版或旧安装版的数据，无需重复导入。安装或卸载前请先从托盘正常退出程序。

本版本已通过图标加载、安装/升级/卸载流程及性能资源回归测试。测试采用隔离目录；发布包不包含个人事项或备份。
